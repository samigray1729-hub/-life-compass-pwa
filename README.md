# Life Compass

目標、日々のTODO、長期的な積み上げを1つにまとめた、スマートフォン向けの個人用PWAです。HTML・CSS・JavaScriptだけで動作し、外部サービスへの通信は行いません。保存先はブラウザ内のIndexedDBです。

## 主な機能

- ダッシュボード：目標値あり／なしのゲージを作成し、日々の達成値を加算
- TODO：チェック式または数値式のTODOを、1日・1か月・任意期間へ一括登録
- 目標ノート：目標やモチベーションを自由な文章で保存
- データ管理：全データのJSONバックアップ／復元、CSV書き出し
- PWA：ホーム画面への追加、インストール後のオフライン利用
- 入力検証：必須項目、正数、日付範囲、復元ファイル形式を画面上で検証

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 3ページ、入力ダイアログ、ナビゲーションなどアプリの画面構造 |
| `styles.css` | スマホ縦画面中心のレスポンシブUI、iPhoneのセーフエリア、配色とアニメーション |
| `db.js` | IndexedDBの初期化と、保存・取得・削除・全件復元の共通処理 |
| `app.js` | 画面遷移、入力検証、各データの操作、集計、JSON／CSV出力 |
| `manifest.json` | PWA名、テーマカラー、起動方法、縦向き、アイコンの定義 |
| `service-worker.js` | アプリ一式のキャッシュとオフライン応答 |
| `icon.svg` | PWA、ブラウザタブ、ホーム画面用アイコン |

## GitHub Pagesで公開する

1. このフォルダの全ファイルをGitHubリポジトリの公開対象ブランチへ置きます。
2. GitHubの **Settings → Pages** で、公開するブランチとフォルダ（通常は `main` / root）を選びます。
3. 表示されたHTTPSのURLをiPhoneのSafariで開きます。
4. Safariの共有メニューから **ホーム画面に追加** を選びます。

相対パスのみを使っているため、`https://ユーザー名.github.io/リポジトリ名/` のようなサブディレクトリでも動作します。Service WorkerはHTTPSまたはlocalhostでのみ有効です。

## ローカル確認

Service Workerを確認するには、ファイルを直接開かずHTTPサーバー経由で表示してください。例：

```sh
python -m http.server 8080
```

その後、`http://localhost:8080/` をブラウザで開きます。

## データとバックアップ

データは利用中のブラウザ・端末内にのみ保存されます。ブラウザのサイトデータを削除すると消えるため、画面右上のメニューから定期的にJSONバックアップを保存してください。復元すると現在のデータはバックアップ内容で置き換わります。CSVは表計算ソフトでの閲覧・集計用です。
